Skip rebuilding local directory dependencies on `pdm install`, `pdm sync` and `pdm add` when their build inputs haven't changed. A content digest of the source tree (project files, build configuration and sources, excluding caches and VCS metadata) is recorded in the installed distribution together with an artifact integrity check; only changed local packages are rebuilt, and concurrent installations of the same local directory are serialized with a file lock. Forced reinstallation still rebuilds everything; distributions installed before this change are rebuilt once and then take part in the skipping.
